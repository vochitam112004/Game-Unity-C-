# Build & Export Guide / Hướng dẫn Xuất bản (Build)

This document explains how to generate a ready-to-run executable for the **Tales of Thach Sanh** game.

---

## 🛠️ Step 1: Open the Build Settings
1.  Open the project in the **Unity Editor** (Version 6000.3.3.f1).
2.  Go to `File` -> `Build Settings` (or press `Ctrl+Shift+B`).

## 📁 Step 2: Add Scenes to Build
Ensure that the scenes are added to the **"Scenes In Build"** list in the following order:
1.  `UI` (Main Menu - located in `Assets/Scenes/00_MainMenu/`)
2.  `IntroScene` (Intro - located in `Assets/Scenes/01_GocDa/`)
3.  `Chuong1_GocDa` (Level 1 - located in `Assets/Scenes/01_GocDa/`)
4.  `02_MieuChanTinh` (Level 2)
5.  `03_HangDaiBang` (Level 3)

> [!NOTE]
> If the scenes are missing, click **"Add Open Scenes"** or drag them from the `Assets/Scenes` folder.

## ⚙️ Step 3: Platform Selection
-   **Target Platform**: `Windows, Mac, Linux`.
-   **Architecture**: `x86_64`.

## 📦 Step 4: Finalize & Build
1.  Click **"Build"**.
2.  Select a folder to save the output (e.g., `Builds/Windows/`).
3.  Wait for Unity to compile the project.

---

## 📁 Project Transfer Guide / Hướng dẫn Gửi Dự án

If you are sending this project to someone else, please follow these steps to ensure the project remains lightweight and stable:

### 1. Clean the Project
Delete the following folders before zipping (they will be regenerated by the recipient's Unity Editor):
-   `Library/` (This folder is usually very large)
-   `Temp/`
-   `Logs/`
-   `obj/`

### 2. Compress the Files
Right-click the root folder and select **"Compress to ZIP"**.

### 3. Verify the Transfer
The recipient should extract the ZIP file and open it via **Unity Hub**.

---

## 🔧 Troubleshooting / Xử lý sự cố

-   **Pink Materials**: If materials appear pink, go to `Window` -> `Rendering` -> `Render Pipeline Converter` -> `Universal Render Pipeline` -> `Convert Built-in Materials to URP`.
-   **Missing Input**: Ensure the **Input System** package is installed via `Window` -> `Package Manager`.
