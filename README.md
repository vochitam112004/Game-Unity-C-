# Tales of Thach Sanh (Truyền Thuyết Thạch Sanh)

A 3D Action-Adventure game based on the famous Vietnamese folklore of **Thạch Sanh**. Journey through ancient landscapes, battle mythical creatures, and uphold your karma.

---

## 🎮 Game Overview / Tổng quan trò chơi

- **Engine**: Unity 6 (6000.3.3.f1)
- **Genre**: Action-Adventure / Nhập vai Hành động
- **Setting**: Ancient Vietnam / Việt Nam cổ đại
- **Protagonist**: Thạch Sanh

### Key Features / Tính năng chính:
- **Karma System**: Your actions impact your progression and ending.
- **Combat**: Fluid melee combat with special abilities.
- **Folklore Reimagined**: Battle iconic bosses like the Giant Python (Chằn Tinh) and the Great Eagle (Đại Bàng).

## 🚀 Getting Started / Hướng dẫn bắt đầu

### Prerequisites / Yêu cầu hệ thống:
1. **Unity Editor**: Version **6000.3.3.f1** or later.
2. **Render Pipeline**: Universal Render Pipeline (URP).

### Installation / Cài đặt:
1. Clone the repository or extract the ZIP file.
2. Open the **Unity Hub**.
3. Click `Add` -> `Add project from disk`.
4. Select the project folder.
5. Wait for Unity to import assets (this may take a few minutes).

---

## 📁 Project Structure / Cấu trúc dự án

- **`Assets/Scenes/`**: Main game levels (`00_MainMenu`, `01_GocDa`, etc.).
- **`Assets/Scripts/`**: All C# logic (Player, AI, Combat, Systems).
- **`Assets/Prefabs/`**: Reusable game objects.
- **`Assets/Art/`**: 3D Models, Textures, and Environments.
- **`Assets/Audio/`**: Sound effects and Music.
